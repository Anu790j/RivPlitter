RivPLitter is an **88,860-frame environmental dataset** created to facilitate sustainable environmental monitoring by detecting plastic debris in riverine environments. 

This repository hosts the **project website and documentation** for the dataset.

---

## 🔬 About the Project

Current computer vision models face challenges with continual learning and efficient annotation in dynamic environments. Collecting data daily and re-training models often leads to catastrophic forgetting, and manual annotation at this scale is extremely labor-intensive. 

To address this, we developed a **semi-automated YOLO pseudo-labeling pipeline** that increased annotation throughput by **10×**, resulting in this comprehensive 88,860-frame dataset. 

This work was accepted at **ACPR 2025 (Springer LNCS)**.
